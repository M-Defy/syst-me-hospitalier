## Stack technique
- **Backend** : Django + Django REST Framework
- **Frontend** : React.js
- **Base de données** : PostgreSQL
- **Hébergement** : Render (backend + BDD) / Vercel (frontend)
- **CI/CD** : GitHub Actions
